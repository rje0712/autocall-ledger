# 🚙 오토콜(AutoCall) 회비 장부 시스템

2026 오토콜 정기 회비 스마트 관리 및 실시간 공개 대시보드 웹 애플리케이션입니다.

- **실시간 웹사이트 주소 (계원 공유용)**: [https://rje0712.github.io/autocall-ledger](https://rje0712.github.io/autocall-ledger)
- **모임원(계원)**: 열람 전용 뷰 (언제나 최신 장부 실시간 열람)
- **관리자**: 엑셀 수정 또는 비밀번호 인증 후 건별 스마트 충당(FIFO) 등록, 월별 일괄 등록 지원

---

## 💡 장부 관리 및 업데이트 방법 (초간단 2단계)

### 1단계: 장부 내역 추가 / 수정
* **방법 A (엑셀로 편하게 관리 - 추천)**:
  - `오토콜 회비 장부.xlsx` 파일을 열어서 새 입금 내역을 추가하고 저장합니다.
* **방법 B (웹 화면에서 관리)**:
  - `장부열기.bat`를 실행하거나 웹사이트에서 **[관리자 로그인]** (비밀번호: 1234) 후 등록합니다.

### 2단계: 웹사이트에 최신 장부 반영
* **`웹사이트_업데이트.bat` 파일을 더블클릭합니다!**
  1. 엑셀 및 데이터의 최신 내용을 웹페이지로 자동 빌드합니다.
  2. GitHub 서버로 최신 장부를 안전하게 전송(Push)합니다.
  3. **계원들에게 보낼 웹사이트 주소가 클립보드에 자동으로 복사**됩니다.
  4. 카카오톡 단톡방에 바로 **[Ctrl + V] (붙여넣기)** 하시면 끝납니다!
