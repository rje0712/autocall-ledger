# 🚙 오토콜(AutoCall) 회비 장부 시스템

2026 오토콜 정기 회비 스마트 관리 및 실시간 공개 대시보드 웹 애플리케이션입니다.

- **실시간 웹사이트**: [https://rje0712.github.io/autocall-ledger](https://rje0712.github.io/autocall-ledger)
- **모임원**: 열람 전용 뷰 (수정 불가)
- **관리자**: 비밀번호 인증 후 건별 스마트 충당(FIFO) 등록, 월별 일괄 등록, 엑셀 가져오기/내보내기 지원

## 주요 기능
1. **스마트 자동 순차 충당 (FIFO)**: 다월 회비(예: 6만, 10만 원) 일괄 입금 시 비워진 가장 오래된 미납 월부터 자동 배분
2. **월별 전체 일괄 등록**: 8명 회원의 당월 납부 상태를 한 번에 체크하여 등록
3. **엑셀 파일(.xlsx) 양방향 동기화**: 엑셀 업로드로 장부 전체 반영 및 엑셀 다운로드 지원
4. **월별 납부 매트릭스 & 카톡 공지 생성기**: 클릭 한 번으로 미납/완납 정산 알림 복사
