# 🚙 오토콜(AutoCall) 회비 장부 시스템

2026 오토콜 정기 회비 스마트 관리 및 실시간 공개 대시보드 웹 애플리케이션입니다.

- **실시간 웹사이트 주소 (계원 공유 및 관리용)**: [https://rje0712.github.io/autocall-ledger](https://rje0712.github.io/autocall-ledger)
- **모임원(계원)**: 언제 어디서나 최신 장부 실시간 열람 (수정 불가)
- **관리자**: 엑셀 없이 **스마트폰/PC 웹 화면에서 바로 등록하고 버튼 하나로 실시간 배포** 가능!

---

## 🌟 홈페이지에서 직접 업데이트하는 방법 (추천! 엑셀 필요 없음)

스마트폰이나 컴퓨터 브라우저에서 언제든 간편하게 장부를 수정하고 전체 공개할 수 있습니다.

1. **웹사이트 접속**: [https://rje0712.github.io/autocall-ledger](https://rje0712.github.io/autocall-ledger) 접속
2. **관리자 로그인**: 우측 상단 **[관리자 로그인]** 클릭 (비밀번호: `1234`)
3. **내역 입력/수정**:
   - **건별 등록**: 입금자, 금액 선택 후 등록 (오래된 미납 월부터 자동 충당)
   - **전체 일괄 등록**: 당월 8명 체크박스로 한 번에 납부 처리
   - **표에서 직접 클릭**: 납부 표의 칸을 클릭하면 완납/미납 즉시 전환
4. **웹사이트 즉시 반영**:
   - 상단의 반짝이는 **`[🚀 웹사이트 즉시 반영]`** 버튼 클릭!
   - *(최초 1회: 본인의 GitHub 토큰을 묻는 창이 뜨면 토큰을 붙여넣기만 하시면 브라우저에 자동 저장됩니다)*
   - **클릭 후 약 30초 뒤 모든 계원의 스마트폰 화면에 실시간으로 즉시 공개됩니다!** 🎉

---

## 💻 컴퓨터에서 엑셀로 관리할 때 (기존 방식도 100% 지원)

1. `오토콜 회비 장부.xlsx` 파일을 열어서 새 입금 내역을 추가하고 저장합니다.
2. `웹사이트_업데이트.bat` 파일을 더블클릭합니다!
3. 자동으로 빌드 및 깃허브 전송이 완료되며, 단톡방 공유 링크가 클립보드에 자동 복사됩니다.
